# Class Deadline Tracker

A web application that helps students organize their academic tasks, monitor upcoming deadlines, and track their progress.

## Features

- Add new school tasks and assignments.
- View and manage task deadlines.
- Track task completion status.
- Organize academic activities in one place.
- User-friendly and responsive interface.

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Git and GitHub

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/tatojastine/class-deadline-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd class-deadline-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Purpose

This project was created to help students manage school requirements, stay organized, and avoid missing assignment deadlines.
